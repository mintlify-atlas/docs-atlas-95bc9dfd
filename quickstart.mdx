This guide walks you through the fastest path to a working local instance of Sistema Viajes.

<Steps>
  <Step title="Install prerequisites">
    Make sure you have the following installed before continuing:

    - **Node.js 18 or later** — [nodejs.org](https://nodejs.org)
    - **MySQL 5.7+ or MariaDB 10.4+** — [mysql.com](https://www.mysql.com) or [mariadb.org](https://mariadb.org)
  </Step>

  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/molina071/TRC.git
    cd TRC
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    npm install
    ```
  </Step>

  <Step title="Import the database">
    Create the `sistema_viajes` database in MySQL/MariaDB and import the provided SQL dump.

    ```bash
    mysql -u root -p -e "CREATE DATABASE sistema_viajes;"
    mysql -u root -p sistema_viajes < BD/sistema_viajes.sql
    ```

    If you prefer phpMyAdmin: create the database manually, then use **Import** to upload `BD/sistema_viajes.sql`.
  </Step>

  <Step title="Configure database credentials">
    Open `config/Conexion.js` and update the connection details to match your local MySQL setup:

    ```js
    const { Sequelize } = require('sequelize');
    const sequelize = new Sequelize('sistema_viajes', 'root', '', {
        host: "localhost",
        dialect: 'mysql',
    });
    module.exports = sequelize;
    ```

    Replace `'root'` and `''` with your MySQL username and password.
  </Step>

  <Step title="Start the server">
    ```bash
    node app.js
    ```

    <Note>
      The server listens on port **3000** by default. Set the `PORT` environment variable to use a different port: `PORT=8080 node app.js`.
    </Note>
  </Step>

  <Step title="Open the app">
    Navigate to [http://localhost:3000](http://localhost:3000) in your browser. You should see the Sistema Viajes login page.
  </Step>

  <Step title="Log in as admin">
    Use the default admin account to sign in:

    | Field | Value |
    |---|---|
    | Email | `jpenia55@gmail.com` |
    | Password | `nancy` |

    This account has the **Gerente de Tienda** (Store Manager) role with full access to all system features.
  </Step>

  <Step title="Create your first trip">
    After logging in you will land on the admin dashboard. From the navigation menu, select **Viajes** and click **Nuevo Viaje** to create your first employee transportation trip.
  </Step>
</Steps>
