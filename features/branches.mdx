## Overview

Branches (sucursales) represent the company locations that employees travel to. Each branch can be assigned to multiple collaborators and serves as a destination in trip creation.

## Data model

Branches are stored in the `sucursales` table:

| Field | Type | Description |
|---|---|---|
| `sc_id` | INT (PK, auto-increment) | Unique branch identifier |
| `sc_nombre` | STRING | Branch name |
| `sc_direccion` | STRING | Branch address |
| `sc_estado` | TINYINT | Record status (`1` = active, `0` = deleted) |

## Soft delete

Deleting a branch sets `sc_estado = 0` rather than removing the row:

```sql
UPDATE sucursales SET sc_estado = 0 WHERE sc_id = ?;
```

<Warning>
  Only branches where `sc_estado = 1` appear in the trip creation dropdown. Soft-deleted branches are excluded but their historical trip records remain intact.
</Warning>
