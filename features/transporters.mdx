## Overview

Transporters (transportistas) are the service providers used to carry out trips. Each transporter has a base rate (`tr_tarifa`) and is selected during trip creation.

## Data model

Transporters are stored in the `transportistas` table:

| Field | Type | Description |
|---|---|---|
| `tr_id` | INT (PK) | Unique transporter identifier |
| `tr_nombre` | STRING | Transporter name |
| `tr_tarifa` | DECIMAL(7,2) | Base rate |
| `tr_estado` | TINYINT | Record status (`1` = active, `0` = deleted) |

## Soft delete

Deleting a transporter sets `tr_estado = 0` rather than removing the row:

```sql
UPDATE transportistas SET tr_estado = 0 WHERE tr_id = ?;
```

<Warning>
  Only transporters where `tr_estado = 1` appear in the trip creation form. Soft-deleted transporters are excluded but trips previously assigned to them retain the association.
</Warning>
